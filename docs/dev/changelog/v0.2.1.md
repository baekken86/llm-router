# v0.2.1

**Date:** 2026-07-19
**PR:** #8 (squash merge cd59eb0)
**Component:** web (Svelte UI)

## Features

- **Flat composition canvas** (CompositionCanvas.svelte, new): root-level `+ Op`, `+ Filter Source`, `+ VM Ref` buttons replace the rooted tree builder. Visual = indent only, no rails, no color bands.
- **Auto-wrap / auto-unwrap**: save wraps multiple roots into a `union` op; load unwraps single-source unions back to flat. Backward-compatible with existing wrapped VMs in the DB.
- **Native HTML5 drag-and-drop** across all rows including op-node source lists. Chosen over dnd-svelte to avoid DragDropProvider single-provider refactor for cross-container DnD. Existing SortableTree (standalone) unchanged.
- **CompositionBuilder** accepts optional `group`, `currentPath`, `onCrossContainerMove` props for canvas integration; standalone behavior preserved when props omitted.
- **VirtualModelForm** swaps CompositionBuilder for CompositionCanvas. Save uses `canvasRef.getComposition()` for the auto-wrapped shape.

## Bug Fixes

- Root-level drop no longer dead code (uses `removeNodeFromComposition` + direct push).
- Single-VM canvas no longer renders blank (template branch added).
- Removed `autoUnwrapInPlace` reactivity hazard; replaced with local `$state` tree + `$effect` for prop sync.

## Breaking Changes

None. Backward-compatible: existing wrapped VMs in DB render via autoUnwrap.
